# 월별 상승 확률 급변 감사 · 2026-10-12

## 판단
**현행 certified 확률엔진을 유지한다.** 2016-01~2026-07의 서울 범위 월별 확률을 당시 이용 가능했던 월별 입력으로 재현했고, frozen 2012-2017 선택 / 2018+ holdout에서 20개 거리·K 후보를 비교했다. 이 연구는 **향후 1개월 상승확률**을 대상으로 하며 3개월/6개월 모델은 변경하지 않는다. 서울은 원천 데이터 범위이며 코드 모델의 상수가 아니다.

| 검증 | 기존 10개 균등 가중 | 10개 역거리 가중 (선택기간 1위) | 15개 역거리 가중 (비교) |
| --- | ---: | ---: | ---: |
| 2012–17 Brier | .406 | .398 | .398 |
| 2018+ Brier | .263 | .259 | .247 |
| 2018+ 상승 AUC | .958 | .956 | .966 |
| 2018+ 상승 ECE | .152 | .151 | .125 |
| 2018+ 3-class 정확도 | 87.25% | 87.25% | 87.25% |
| 2018+ 평균 월간 확률 절대변동 | 12.0%p | 12.5%p | 12.2%p |

**10개 역거리**는 2012–17 선택기간에서 가장 낮은 Brier를 얻었다. 다만 그 기간의 상대 개선은 2% 미만이며 2018+ 개선도 약 1.5%다. 예측력 AUC가 근소하게 나빠졌고 변동성도 증가했다. 12개월 이동블록 paired bootstrap Brier 개선 95% 구간은 약 [-.004, .014]로 0을 포함한다. **유의한 production 승급 근거가 없다.**

**15개 역거리**는 holdout Brier에서 더 좋은 결과였지만, 선택기간 최적 후보가 아니며 이 결과를 보고 채택하는 것은 holdout을 모델 선택에 다시 사용하는 행위다. 6개월/12개월 paired block bootstrap 개선 구간은 양수였으나 이것만으로 승급할 수 없다. 선택 기준을 사후 조정하거나 2018+를 재학습에 사용하지 않는다.

## 재현 및 안전장치

- python3 scripts/audit_upside_probability_stability.py --check
- python3 scripts/audit_upside_probability_stability.py --json /tmp/upside_stability.json
- 공통 산식은 scripts/build_upside_probability_engine.py에서 재사용한다. 2012년 이전 값으로 보합 구간을 고정하고, 당시 이미 결과가 확정된 학습 행만 포함한다.
- 선택기간(2012–17)에서 후보 선정, holdout(2018+)은 후보를 고르기 위한 재튜닝에 사용하지 않는다.
- 1개월 다중분류 Brier, AUC, ECE, accuracy, macro F1, 월간 점프, 상승 전환점 탐지시차 및 paired block bootstrap을 함께 산출한다.
- 주의: 장기 시계열은 현재 저장된 과거 **수정치(vintage)**이며, 당시 처음 발표된 원천 vintage까지 보존한 것은 아니다. 엄격한 실시간 재현을 주장할 수 없다.
- 2026년 월간 장기 시계열 마지막 관측은 **2026-07**이다. 2026-09-28 주간 입력 기반 현행 확률(69.2%)과 월별 연구 결과는 직접 비교하지 않는다.
- 인증된 3/6개월과 검증 거부된 12개월 엔진 및 UI/production JSON은 변경하지 않았다.

## 승급 조건

시계열 사후 선택 편향을 피하도록 후보 선정 규칙을 고정해야 한다. 감사 도구는 선택기간 Brier 최소 후보만 검토하며, 선택기간 Brier 3% 이상 개선, holdout Brier 5% 이상 개선, AUC·ECE 유지/개선, 월간 확률 변동 악화 없음, 전환 탐지 지연 악화 없음, 6/12개월 블록 부트스트랩 개선 신뢰구간 양수인 경우에만 **별도 재인증 검토 후보**로 표시한다. 감사 결과는 production 교체 권한이 없으며 승급은 독립적인 평가와 원자적 변경으로 수행한다.
