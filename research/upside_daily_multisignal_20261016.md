# 일별 상승 확률 다중 신호 연구 후보 — 2026-10-16

## 운영 범위와 목적
현재 생산 환경은 서울시를 market scope로 사용하지만 모델은 지역명에 종속되지 않는다. 인증된 1개월 상승 확률은 REB 주간 매매가격지수의 4주·13주 가격 모멘텀만 입력으로 사용한다. 이로 인해 매일 새로 들어오는 금융·KB 심리·거래 입력이 주간 가격 발표 사이에 인증 확률을 변화시키지 못하는 한계가 있다.

이번 변경은 **인증 확률을 변경하지 않고**, 금융·심리·거래 공통 Feature Layer를 사용하는 **일별 실험 후보 확률**을 병행 생성하고 서버에 날짜별로 기록한다.

## 입력, 시점, 출처
- 금융: 시장 판단 공통 Feature Layer의 finance 값. 관측 근거의 주택담보대출 원자료 월과 기준금리 관측일을 별도 보존한다.
- 심리: 같은 Feature Layer sentiment 값. KB 매수우위지수의 실제 주간 관측일을 보존한다.
- 거래: 같은 Feature Layer demand 값. MOLIT의 **신고완료 월**을 사용하고 당월의 미신고 거래를 정상 모집단으로 취급하지 않는다. `fallback_last_good`은 마지막 정상값으로 분리한다.
- 원천의 마지막 `collected_at`과 실제 지표의 관측 기준일을 혼동하지 않는다.
- 불완전한 값은 0/중립으로 대체하지 않고 `data_check`로 보낸다.

## 연구 엔진
인증된 KNN 10 기준 확률을 prior로 두고 finance/sentiment/demand 3개 지표의 정규화 잔차만 L2 벌점(logistic ridge λ=10)으로 보정한다. 지표별 평균 및 계수는 2022-09~2024-12 과거 선택 구간에서만 적합한다. 2025-01 이후는 고정된 계수를 평가하는 과거 holdout으로 사용한다. 월별 전방 결과가 실제 관측되기 전이면 샘플에서 제외한다. 이는 가격의 인증 기준과 독립되지 않은 **참고 연구 후보**이며 3·6개월 엔진은 변경하지 않는다.

월간 금융·심리·거래 과거 연구 피처는 사후 정리된 데이터로서 해당 예측 시점에 공개됐던 진정한 vintage를 완벽히 재현하지 못한다. 또한 학습·검증 표본이 각각 최소 36·24개월을 충족하지 못할 수 있고, 독립적인 미래 평가도 아직 완료되지 않았다. **따라서 certified 승격 불가** 상태를 고정한다. 홀드아웃 Brier가 개선되더라도 그것만으로 production에 적용하지 않는다.

## 화면 및 운영
- 인증 확률(현재 61.5%)은 주 확률로 그대로 유지.
- 바로 아래에 `금융·심리·거래 일별 신호(검증 전 연구 후보)`를 표시해 기존 확률과 연구 후보의 차이를 분리한다.
- 값과 관측일, 원천 상태, 과거 홀드아웃 성능을 원하면 펼쳐 본다.
- `dist/upside_probability_history.json`의 `daily`는 기존 인증 확률 기록을 유지한다. `research_daily`는 새 후보의 실측 일별 스냅샷으로 별도 누적한다. 과거에 존재하지 않는 데이터를 임의 생성하지 않는다.
- 기존 매일 08:00 시장 수집 → 연구/전망 build → 일별 후보 계산 → 추적 기록 commit → 검증 → Pages의 흐름에서 자동 업데이트된다. 수동 갱신에서도 같은 경로로 계산된다.
